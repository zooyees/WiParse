# 串口AI对话界面与全局入口调整

## 问题与修正

原串口侧栏直接使用报告排版，标题、正文与微小状态文字比例不协调；重复宿主通知占用正文空间，底部多个同等权重按钮干扰输入。现使用独立的聊天Markdown渲染：正文14px、标题最高16px、元信息12px，代码13px。表格按侧栏宽度分配，长标识允许换行；多列表格和代码块可横向滚动。

用户消息使用轻量气泡；AI回复直接排版，复制与时间收在回复末尾。普通宿主通知折叠为活动记录，连续相同通知合并；错误、预警仍直接显示。数据范围、文本输入、控制权限及发送/停止整合为固定底部输入区。

按用户要求，主工具栏独立AI按钮移除，通过“设置 → AI”进入全局助手；串口“AI窗口”保留。

## 影响范围

修改限定于串口AI视图、独立聊天Markdown渲染、相邻通知去重及主工具栏入口。报告Markdown原渲染保持原实现。平台工具白名单、操作权限、请求会话绑定、测试锁、后台预警、全局服务配置和串口数据保留参数不变。
