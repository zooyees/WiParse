# GUI 持续优化 R36（2026-11-09）

## 问题与修正

1. 波形固定七位有效数字直接输出长小数，纵轴在 74px 左边距被裁切，横轴首尾居中也可能超边。极大时间偏置配极小时间跨度时，原标注还可能重复。新增统一坐标格式：普通范围保留有效精度，微小/大范围采用公共指数，大偏置采用显式 offset；首尾刻度分别左/右对齐，并限制绘制宽度。坐标绘图、鼠标命中及地线手柄共用边距；手柄移入绘图区，避免压住纵轴数字。原始数据、游标读数、统计及导出不变。
2. ResizeObserver 与主题改变直接同步重绘，更新密集时重复进行画布工作。改为每个绘图实例最多一个待执行动画帧；同帧事件合并，依赖变化或卸载取消旧工作；像素尺寸未变时不重复重置 canvas backing store。增加窗口 resize 通知以重新匹配像素比。没有调整采样预算、极值保留或解码逻辑。
3. 计算器只按浏览器窗口宽度切换单列，拖宽左栏后，实际右侧内容已经变窄仍按双列布局。新增 calculator-pages 容器查询，按实际内容宽度切换，窄区结果边框也改为上下分隔。
4. 叠加已支持相同横轴、不同纵轴单位，旧提示仍写“横纵轴都一致”。提示改为与 overlayCompatible 使用同一判定，中文和英文均更新。
