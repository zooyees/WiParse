# WiParse AI 工程契合度整改记录

对应[工程契合度评审](ai-wiparse-engineering-fit-2026-11-11.md)。本次基于 1.2.2 egui 工作树修改宿主、数据工具和测试。上一份 DataLayout 预览 EXE 早于本次修改。

| 评审问题 | 已落实 | 验证及边界 |
|---|---|---|
| 缺参被显示为完成 | 共享助手和串口助手保留 `needs_input`；已授权读取仍由宿主直接执行。待补充时停止自动追问，同一来源的下一轮输入可保留原有目标。 | 共享助手模拟原生和 JSON 返回缺参，存在开放目标时仅请求模型一次。串口保留原有授权、取消和来源约束。 |
| 文件提取无法交给绘图和报告 | `data.extract` 可保留本地数据集并返回句柄。`data.present` 使用该句柄；文件报告按同一份点列生成 PNG 和 CSV。横轴支持记录序号和指定时间列。 | 文件回归覆盖原单位、图上换算、表头、空值、非法值、换源失效和导出 CSV 逐行核对。超出点数限制仍返回统计，不将截断点列当成完整结果。 |
| 扫描结束被理解为识别成功 | 扫描覆盖与识别结果分别返回；零帧、全无有效值返回工具失败，缺失、非法、时间倒退分别计数。 | 合成样本覆盖有内容但帧头不匹配、列不存在和部分数据有效。 |
| 多目标任务缺少统一验收 | 两入口共用工作流证据。报告文件需要实际报告 ID，完整周期需要边界和覆盖，协议结论需要解码证据。常见明确的组合请求自动登记目标，其他表达由模型创建结构化计划。 | 串口端到端回放从一次自然语言请求生成实际功率曲线和报告文件。自动登记采用有限词组，任意自然语言表达的识别率仍需真实模型评测。 |
| 混用日志时钟与采样时钟 | 返回时钟域、波形采样间隔信息；`agent.align` 用观测到的两对边界作区间内换算。条件误差上界须有两个边界的误差和剩余漂移上界。 | 已知偏移与漂移、边界外拒绝有合成回归。硬件同步点可使用既有服务 `time.mapping.fit/convert` 做三点及以上拟合和残差门控。两点估算不能证明采集设备已同步。 |
| 高频参数发现和任务成本难评价 | 能力帮助公开宿主校验使用的参数名；平台目录补充页面、作用及同名规范工具契约。任务结果与提供方 usage 通过任务 ID 关联，支持离线统计完成时延与 Token 分位数。 | [本地统计脚本](../../scripts/summarize-ai-tasks.py)仅统计观察到且有完整用量的成功任务，其他任务保留在对应分母。设备和插件的运行时参数仍以实际设备能力、当前插件描述与预检为准。 |

## 验收范围

Core 与 GUI 离线全量回归分别为 318 和 302 项通过，8 项既有忽略。串口最终补充旧来源回复丢弃逻辑与缺参回放后，重新运行串口 AI 模块，49 项全部通过。两入口均回放了带开放目标的缺参回复，验证原生和 JSON 响应形式。任务统计脚本用合成日志核对了完整用量和缺失请求两种分母。

本地覆盖核心库、GUI、模拟模型、模拟仪器和临时工程文件。费用、自然语言诊断正确率、真实设备的告警延迟与同步误差均需要现场数据；本次没有拿合成用例推算这些指标。监控频率、设备权限、现有产品判定和本地告警策略沿用现有行为。调用示例见[AI 接口说明](../AI_INTERFACE.md)。
