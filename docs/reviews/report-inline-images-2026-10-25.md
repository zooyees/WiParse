# 测试报告截图直接显示

日期：2026-10-25；WiParse 1.2.2 独立 EXE 预览。

原因为报告生成器将截图输出为普通文件链接。宿主虽然支持 Markdown 图片，但普通链接会进入独立图片预览。

已调整：

- 示波器/串口插件 0.7.1 在每轮记录的“波形截图”段输出 `![波形截图](相对路径)`。缺少截图时明确显示提示，不伪造图片。
- FPGA 报告的图片证据同样嵌入正文；波形源文件、日志、PDF 和结果 JSON 保持链接形式。
- 旧报告无需改写：宿主显示时把正文、列表、表格中的本地图片链接提升为内嵌图；表格仍保持紧凑，图片在其下方按可用宽度等比显示。
- 图片及其标题不再触发跳转；其他数据链接的行为保持不变。AI 文本使用原有独立 Markdown 路径，不读取本地图片。
- 长报告仅在截图进入可见区域时解码；清理多余的不可见纹理，通常保留最多 16 张（当前可见图片多于 16 张时保留所有可见图）。沿用原有文件大小、显示边长和目录访问限制。

验证：

- 报告 Rust 测试 25 项通过，包括实际纹理绘制、图片点击不跳转、旧链接兼容、其他附件链接、目录限制及长报告加载/缓存。
- Node 测试 16 项通过，包括串口触发、示波器报告与 FPGA 报告输出。
- 六组新旧报告界面帧覆盖 640/1100/1920 像素宽度及深浅主题；其中四组已生成效果图，并复核新旧报告的 1100 像素浅色画面。
- 最终 EXE 冒烟通过：七个工具页、八类模拟设备及旧 Markdown、JSON、日志、PNG、ISF 文件打开。

只读兼容不会改写历史报告。不存在的图片仍显示缺失提示，越界或网络图片仍受原有访问限制。未执行真实硬件采集，不宣称本轮重新验证所有仪器功能。

预览位于 `dist/wiparse-1.2.2-report-images-20261025-preview/bin/WiParse.exe`，包含此前 USB 重连、源文件后台管线和串口触发可视化修正。未覆盖旧预览或根 EXE，未生成完整 ZIP。
