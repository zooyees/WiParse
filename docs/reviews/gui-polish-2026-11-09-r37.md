# GUI 持续优化 R37（2026-11-09）

## 问题与修正

1. 波形固定七位有效数字直接输出长小数，纵轴在 74px 左边距被裁切，横轴首尾居中也可能超边。极大时间偏置配极小时间跨度时，原标注还可能重复。新增统一坐标格式：普通范围保留有效精度，微小/大范围采用公共指数，大偏置采用显式 offset；首尾刻度分别左/右对齐，并限制绘制宽度。坐标绘图、鼠标命中及地线手柄共用边距；手柄移入绘图区，避免压住纵轴数字。原始数据、统计计算及导出不变；范围与游标读数按当前跨度自适应保留 7–17 位有效数字，避免大偏置下显示成同一点。
2. ResizeObserver 与主题改变直接同步重绘，更新密集时重复进行画布工作。改为每个绘图实例最多一个待执行动画帧；同帧事件合并，依赖变化或卸载取消旧工作；像素尺寸未变时不重复重置 canvas backing store。增加窗口 resize 通知以重新匹配像素比。没有调整采样预算、极值保留或解码逻辑。
3. 计算器只按浏览器窗口宽度切换单列，拖宽左栏后，实际右侧内容已经变窄仍按双列布局。新增 calculator-pages 容器查询，按实际内容宽度切换，窄区结果边框也改为上下分隔。
4. 叠加已支持相同横轴、不同纵轴单位，旧提示仍写“横纵轴都一致”。提示改为与 overlayCompatible 使用同一判定，中文和英文均更新。

R36 自动验证通过后，桌面大偏置样本进一步暴露旧范围读数仍为七位精度。已补齐范围、X/Y 游标和原始极值读数精度，并冻结为最终 R37；R36 不作为最终交付。

87 项前端测试通过，新增覆盖微小坐标精度、大偏置下独立刻度、零与极端有限范围、100 次调度合并成一个待绘制帧、销毁后取消与拒绝旧回调。R35 的显示精度回归曾失败，已保留失败证据，未打包交付。

动画帧回归验证的是调度机制，没有进行系统 CPU/内存基准测量，不能据此声称资源占用降低了某个百分比。完整自动证据见 docs/verification/next-candidate-20261109-r37/candidate.json，桌面检查单列 desktop.json。

## 影响范围与回归边界

绘图的缩放、平移、框选、游标点击与地线手柄统一使用 PLOT_INSETS，不允许只改画布边距而让命中区沿用旧常数。读数精度只影响字符串格式；后台采样索引、原始 f64、测量范围、阈值、协议帧、导出文件不改变。

动画帧只在数据/尺寸/主题变化时请求，不自行常驻循环；卸载或依赖变化后取消待执行帧，避免旧图覆盖新图。与此前“隐藏工具停止展示轮询”保持兼容。

窄栏计算器的 CSS 与 R36 实测版本一致；1103px 窗口、480px 左栏的 LC 单列及 159154.94Hz 计算结果，保留在 R36/desktop.json 和截图中。最终 R37 的新范围/游标读数桌面证据独立记录，不把基线截图伪装成重新测试。
