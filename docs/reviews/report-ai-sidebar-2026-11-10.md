# 测试报告 AI 侧栏

## 使用

测试报告页面顶部点击“AI 分析”，右侧打开可拖动调整宽度的 AI 窗口。连接设置复用工程现有全局 AI 服务，不需要再填写另一套密钥。

可直接提问，也可选择报告总结、异常分析、工程内报告对比、生成独立分析报告等快捷问题。输入区固定在下方，对话和执行证据独立滚动；支持 Ctrl+Enter、复制、停止、清空，以及 Markdown/Mermaid 显示。配置启用流式时显示正文草稿，工具参数仍完整验证后执行。

关闭侧栏只是收起界面，当前任务继续执行；停止按钮才取消等待。切换到其他工具也不改变报告任务的来源。并发额度与全局/串口助手共享。当前是单任务会话，运行时可以编辑下一条问题，发送需等待当前任务结束。

## 分析与处理

- 独立 Agent Session，复用现有工具执行、证据、权限和取消机制，不与串口或全局窗口混用对话历史。
- `report.inspect` 获取工程报告索引，`report.read` 分页读取当前文本报告或真实索引 ID 对应报告，`report.search` 从本地完整文本检索特定问题。
- `report.read` 返回原始行号、实际来源、后续页码与截断/编码说明。每页最多 200 行、约 16 KiB 文本，每行最多 4 KiB；每次本地扫描上限 16 MiB。大文件可以转用已有检索引擎。分页不是把整份文件一次上传到模型。
- 来源限定当前工程目录；未知或过期 ID、目录外文件、非文本文件、取消、读取时文件更新都返回明确错误。
- 报告来源包含路径、大小与修改时间；切换报告/工程或报告文件更新后停止旧任务、清理旧对话与证据。AI 自己成功打开生成报告时使用既有宿主转换机制衔接任务。
- 可通过 `report.create` 生成独立 AI 分析报告，通过 `report.open` 打开。保存目录由宿主管理，不覆盖原始测试报告，不修改正式通过/失败判定。
- 默认允许读取报告与可逆界面操作；跨工具默认关闭。设备/测试动作仍需要确认具体参数。读取和分析不要求用户反复确认。

## 边界

本次是文本报告分析。模型没有因此获得图片视觉理解：Markdown 中有截图不表示已读懂截图。波形附件需使用相应波形工具取得实际数据，缺少数据时应报告限制。报告页面已有图片内嵌显示与链接打开行为保持原实现。

## 验证

验证覆盖报告分页/行号、末页、取消、工程目录边界、过期 ID、报告变化身份、来源切换清理，以及明暗主题、中英语言、620/1200 像素窗口下的侧栏布局。另运行报告与 Agent 相关回归，结果见 `docs/verification/report-ai-20261110/`。

未使用真实付费 AI 服务或实际仪器做端到端测试。本次为源码与验证记录，之前的 EXE 预览不包含本次变化。
