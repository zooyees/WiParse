# Testing Hub 1.2.1 联合整改验收记录

本次以 `fpga-testing-hub-ui-remediation-2026-10-18.md` 和 `fpga-testing-hub-r0-contract-2026-10-18.md` 为基线。软件工程独占宿主、公共基础层、整合验收和打包；插件开发负责插件、生成定义和20项配置；系统架构只读复核关键资源安全缺陷。原有0.4.0成果保留，没有并行覆盖宿主文件。

矩阵独立页在最后复核补齐运行/预检来源和配置SHA/草稿变化提示；原历史结论保持不变，不能被误当成当前内容的结论。

直接reject未进入取消确认是架构在103项阶段测试之外发现的确定性遗漏；补修并增加断言后才进入新增故障矩阵证据，未以旧测试数替代关闭结论。

发行联调还检出配置锁竞争导致预检偶发失败，以及插件初始化迟删Stop可能丢失停止请求。宿主只对尚未进入操作的互斥竞争有界等待；插件不再清Stop，并在acquire前后、reset前检查。真实进程竞争、等待中Stop和受控重新启动均加入回归。

## 源码与交互证据

Rust全工作区422通过；整合Node226通过；MCP6工具、14项Hub分派检查通过。插件冻结62文件，包含20项原始业务配置，证据清单及逐项F01—F16边界随插件保存。宿主冻结另绑定84个随包文件及124个Rust构建输入。

真实Hub/runner运行20项正例：20 PASS；20项故障模拟：20 FAIL，没有提升为PASS。两套报告各62个证据链接均存在。最终Release GUI连续三次新启动，每次20项均通过，并完成暂停/继续/停止及MD/图片/波形/日志/JSON附件跳转；7个页面和8类模拟仪表也已运行验证。

UI使用实际egui绘制输出，不是设计稿。两份代表性配置分别覆盖COM/DC和Dongle UART/Dongle复位：共112个源帧场景，包含9分组、矩阵、规则摘要和详情、640/1100/1440/1920宽度，以及选定场景的中英文、明暗主题。不是宣称所有20项配置逐页经过人工鼠标操作；20项均通过真实配置API与runner。选定截图见 `../ui-testing-hub-1.2.1/`，最终EXE与截图源码哈希绑定在发行验证摘要。

20万行模拟日志约6.49MB，隔离保存过程约254ms，观测进程峰值RSS约207MiB。此测量包含构造与校验输入，并非真实串口持续接收；它不能证明最长老化、设备定时或串口吞吐达标。

## 发布和保留边界

当前源码与交互门槛已通过；发行EXE、包内容、可移动目录及哈希门槛以最终 `docs/verification/release-1.2.1.json`、`release-manifest.json` 和 `source-freeze.json` 为权威记录。没有这些最终记录时不能把阶段检查写成发行通过。

发布配置保留原始20项业务内容及完整时序。历史演示报告来自独立缩短时序的模拟快照，当前配置需要重新预检和运行，不承接历史PASS。示例固件仅为模拟占位。

未完成范围：合格真实硬件适配器、物理取消和安全恢复、T0实机精度及不确定度、目标最长老化、真实500项执行压力、真实串口吞吐、完整发现入口一致性。缺失硬件能力必须阻断，不能静默模拟。固件下载继续明确阻断，`industrial_approved=false`。F01—F08保持原P1分级、F09—F16保持原P2分级；阶段回归通过不等于16项实机全部关闭。
