# GUI 持续修正与布局优化 R34（2026-11-08）

## 计算器空白

根因在组件组合：ResizableWorkspace 将 children 展平成数组后只渲染 parts[0] 和 parts[1]。计算器把左栏和八个 WorkspaceSlot 直接作为子元素传入，导致仅 LC 对应的第一个工作区被渲染，其余七项被丢弃；切换时只隐藏 LC，右侧因此空白。已将八个保留工作区整体包入唯一的 calculator-pages 右侧容器，沿用原算法与表单状态，不重写计算逻辑。

## 波形优先布局

原波形页将显示映射、16 路协议操作及解析配置与结果固定堆叠在绘图区下方，消耗大量高度。新布局把辅助内容放入独立滚动的右侧“分析设置”，默认收起，可随时展开；主绘图区占满工具栏下方可用空间。底部读数有界滚动，协议结果和参数不再挤压绘图区高度。

工具栏保留平移、光标、测量、缩放、导出和分析设置入口。展开侧栏后宽度为 260–320px，波形保持完整高度；窄窗口保留水平滚动，避免遮挡控件。幅度映射、门控、解码、协议报告和原始数值语义不变。

## 报告工程隔离

包含本轮 R33 的修正：主窗口当前工程透传、目录读取最新请求门控、工程 A→B→A 身份重置、隐藏页停止旧读取回写、添加/移出确认绑定原工程、迟到操作反馈隔离。打开的独立报告仍保留阅读状态。
