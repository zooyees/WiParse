# 串口 AI 全范围日志处理与波形页原生协议分析

日期：2026-11-09。基线：`cursor/four-job-shell-and-marketplace`，原 egui 框架，1.2.2。未合并 Tauri 分支。

## 已落实的功能

### 串口 AI：全部范围在本地处理

默认入口由“最近100行”改为“当前日志 · 全范围”。另提供指定行范围、选中内容、本地日志库和仅提问。手动对话不再隐式附加最近100行原文；AI 使用 `log.files` / `log.analyze` 获取统计和有限证据。

- 当前文件：后台流式扫描完整磁盘文件，仅限当前页，不隐式扩大至其他页或目录。
- 行范围：主机将查询范围与用户指定范围求交；上下文也不能越界。
- 实时数据：共享不可变行快照，保留现有5000行显示限制；沿用会话绝对行号。已淘汰行数明示，不冒充已分析；完整历史选择落盘日志。
- 选区：在本地分析实际选中文字，不再由AI入口截断为8000字符；行号为选区相对行号。
- 日志库：用户选择目录递归扫描，支持已打开文件及当前主串口的落盘记录，按规范路径去重。AI只能使用来源ID，不能指定任意路径。

支持关键词/排除词、正则、归一化分组、数值最小/最大/均值及阈值计数、异常上下文。查询状态最多4份，全局扫描线程最多2个。单批默认1 GiB / 15秒工作预算，允许64–4096 MiB；超过预算可凭不透明游标继续，统计累计而非增量，不能重复相加。

报告核心最多6000 UTF-8字节；来源/错误/分组/样例数量有界，报告说明截断与覆盖缺口。巨大文件不会整体读入字符串。实时快照采用共享行引用，不在UI线程扫描文本。“本地预分析”无需AI服务、不消耗token。自动监控仍维持有界采样和本地告警；没有改变串口采集行数、云请求周期与设备控制授权。

限制：当前文本引擎支持UTF-8。无效编码、疑似UTF-16、超过64 KiB的单行、变化/截断文件、目录容量上限均明确报告不完整。正在增长的文件只读初始字节范围，半截末行不算测量。不读取未保存磁盘编辑；未落盘且已淘汰的历史无法恢复。全范围手动分析不是实时安全联锁。

### 波形页：面积优先

波形页面外边距由8缩至2像素，组件间距由12缩至4像素，辅助卡片内边距由12缩至6像素。移除主图重复标题和卡片内壳。工具栏按当前帧实际换行高度分配，不使用固定档位空行；协议栏按窗口宽度保持200–280像素，主图获得更多横向面积。坐标刻度、光标、缩放、通道零位等交互保留。

电压自动适应保持中心和大幅信号的余量，小信号采用默认500 mV/div的显示保护范围，避免微小噪声被默认放满屏幕。只影响自动显示及低幅通道自动错位间隔，不改变原始数据、测量与协议解析。手动仍可到1 mV/div及更低。

### 协议分析：原生页内显示

移除运行时“在浏览器中分析”及HTML生成/外部打开路径。协议设置保留在右栏，报文与字段在主图下方原生展示；可收起报文区恢复主图面积。原HTML模块仅保留历史回归测试，不进入发布EXE运行路径。

报文表支持摘要/HEX筛选、仅异常、虚拟滚动；宽窗口并排显示字段，窄窗口切换报文/字段。点击报文定位主波形与对应原始帧。字段含协议解释、物理数值、时长、原始字节与完整性，并支持独立滚动。超过256字节的超长报文明确显示预览范围，不将截断内容重新解释为完整字段/CRC；完整解码结果保留。

SCP PING作为底层时序记录保留，用于时钟恢复与请求/应答关联；不列为数据报文、不占数据计数或波形报文标注。其他协议的合法PING消息保持原样。过滤在图形抽样之前完成，避免大量PING消耗抽样预算；筛选和点击保留原始帧索引。

## 验证

验证日志位于同目录；最终数量以 `validation-summary.json` 为准。

- 工作区完整测试：当前Windows用户DPAPI环境运行，避免受限沙箱的密钥加解密失败；测试密钥为合成数据。
- 本地引擎：覆盖全文件首尾证据、UTF-8跨块续扫、目录去重、数值计数、范围/上下文边界、长行/编码/文件变化、分组容量与报告字节预算。
- 串口AI：本机模拟AI连续工具调用，10002行原文不进入请求；仅有一份有界统计，不重复附加原文或工具结果。
- 波形布局：640/1100/1600像素，中英文，主图到底、工具栏不重叠、不额外保留空行。
- 原生协议：8192条混合记录过滤出4096条数据报文，只渲染可见表行；点击定位原索引、字段滚动到CRC、完整HEX筛选及超长预览边界。
- 无真实AI联网请求、无真实仪器控制验证。另对本机 `sample_waveforms/SCP/Normal.isf` 实测捕获文件执行了解析与原生GUI回归：278条底层记录、60条数据帧、218条PING。默认跳过的这两项参考捕获测试已单独执行并通过。截图来自离线捕获，不等同完整硬件联机验收。

## 使用

串口AI选择范围后，可先点“本地日志：设置与预分析…” → “本地预分析”，检查覆盖行数。随后提问如“分析整个日志的timeout分布，并给出前后文”“统计VIN最小/最大值，找低于4.5 V的区间”。AI按需调用本地引擎，不需要把全部文件上传。

波形页加载源文件，右侧选择协议和通道后即可在页内查看结果。点击报文定位；点“收起报文列表”将空间还给波形。SCP报文列表中的帧序号保持底层索引语义，不因隐藏PING而错配字段。
