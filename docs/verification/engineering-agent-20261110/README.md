## 使用与验收

1. 打开独立预览目录bin/WiParse.exe；保留整个相邻资源目录。
2. 设置菜单中保存AI服务与自己的Key，连接测试成功后启用。预览不带本机密钥。
3. 打开实际日志/波形/报告，在相应页面打开AI的“智能任务”。默认只读本页数据；跨工具或调整界面需明确开启。
4. 可问“先检查当前数据，再给出异常证据和下一步”“统计当前日志全部范围的超时及温度分布”“测量通道0指定时间段并解释采样质量”。缺少通道/协议/设定值时应补充，不让模型猜测。
5. 仪表和测试动作会显示具体调用参数，确认后才下发。取消等待不撤回已发动作；异常时核对设备真实状态。
6. 展开E证据核对来源、单位、覆盖和实际完成状态，再导出分析记录。正式测试判定仍以测试报告为准。
