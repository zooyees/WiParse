# 布局与浅色模式整改记录

日期：2026-11-10。原egui 1.2.2框架；不变更驱动、协议算法、测试流程与串口行数限制。

## 发现与修正

| 范围 | 实际问题 | 本轮修正 |
|---|---|---|
| 数据规则 | 标签长度影响控件起点，阈值输入随内容变宽，单位分散 | 每行预留固定标签与控件矩形，输入28px高；阈值勾选、数值、单位统一栅格 |
| 数据侧栏 | 目录默认占42%高度，规则区窄且拥挤 | 默认248px宽仍可拖动；目录高度按内容用途收敛；规则保留滚动与应用流程 |
| 报告侧栏 | 项目下拉、刷新、半宽按钮和说明混杂 | 标题与刷新同行；项目选择、添加、跳转按钮统一宽度；测试记录独立层级 |
| 公共配色 | 浅色绿色/橙色文字过亮，强调色同时承担文字和按钮填充 | 区分accent与accent_fill、stop_bg与stop_fill；调整成功、告警、错误、链接和输入边界 |
| 错误提示 | 多处固定LIGHT_RED用于浅色背景 | 测试工作区、表单、项目矩阵改用语义错误色；同步计算器/转换器和升级提示 |
| 蓝底按钮 | 部分连接、读取屏幕、AI发送按钮未指定前景色 | 明确匹配填充色的前景，保持正常、悬停和禁用状态语义 |
| 数据图 | 坐标浅色文字落在白色边缘，读数黄/青文字在白浮层难辨 | 浅底图、深坐标；曲线/阈值及读数颜色按背景调整，浮层使用不透明背景 |
| 波形图 | 明暗主题共用亮色通道和协议标记；图例、坐标与背景不匹配 | 浅色使用浅底，显示颜色按背景适配；修正光标、协议包/字节/位及通道标识 |
| AI窗口 | 内部固定最大宽度及最小尺寸可超出窄视口 | 根据实际视口约束宽高；增加输入框不得超出视口的断言 |

## 验证范围

- 已通过公共语义配色与输入边界对比、共享表单左右边沿测试。正常正文、辅助文字、状态、链接、主要按钮文字对比目标为4.5，浅色输入边界目标为3；不是全软件无障碍认证。禁用控件继续采用减弱显示。
- 最终GUI全量回归257通过、6按需忽略；包括AI窗口窄视口断言、共享配色/对齐检查和位级协议文字的实际绘制对比检查。发布文件校验见交付记录。
- 新增30帧侧栏/页面渲染：5种页面、3种宽度、2种主题，含实际曲线和Markdown报告夹具。另复查8种仪表、AI设置/助手、串口和波形参考页面；既有矩阵覆盖中英文及1/1.5/2倍缩放。
- 使用真实egui组件离线渲染，仪表为模拟会话；没有执行真实硬件输出或真实收费模型请求。人工截图评审发现的问题先修正，再补充几何或配色检查，不再把“能渲染”作为完整视觉验收。

最终冻结版本GUI回归257通过、6按需忽略，见cargo-delivery.log。直接运行测试程序时需保留Cargo资源定位环境；缺少该环境会造成插件路径测试失败，最终验证采用cargo test重新通过。

协议位/Chip文字在统一绘制层按实际背景校正，覆盖未逐一配置颜色的细节状态；不改变解码内容、时间戳、匹配结果或采样数据。

预览默认浅色，可在设置切换深色。`examples/ui-review`提供合成的数据日志和PWM CSV，步骤见同目录README.txt。
