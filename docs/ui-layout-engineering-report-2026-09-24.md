# WiParse 界面布局整改报告（给软件工程）

日期：2026-09-24

版本：1.1.27

分支：`cursor/four-job-shell-and-marketplace`

读者：GUI 实现（`crates/wiparse-gui`）

范围：全工程界面检查；本报告的实现范围是**串口工具**和**仪器控制**的控件对齐。信息架构（四作业导航、市场抽屉等）不在本次改动内。

目标：布局整齐、美观、协调、优雅。不重做配色，不改业务逻辑。

相关旧文：`docs/ui-optimization-report-2026-09-23.md`。该文里的侧栏 215px、字号 11/12/13/15 已过时。当前令牌是侧栏 **272**、控件高 **28**、字号 **12 / 13 / 14 / 16**（`theme.rs`）。

---

## 1. 结论

主题令牌可以保留。串口和仪器「不整齐」来自同一行里控件的**宽度、高度、右边缘各自计算**，不是配色问题。

请先在 `theme.rs` 增加统一的行网格，再改两个页面。不要在各页面继续写死 22 / 24 / 26 / 28 / 32 和 6 / 7 / 8 圆角。

2×2 仪器格子的外框分配（`instrument_grid_row`）是齐的，不要动。乱在格子内部和左侧仪器卡。

## 2. 必须遵守的布局合同

实现前把下面六条当成验收标准。中英文都要过。

| 规则 | 要求 |
|---|---|
| 高度 | 可点控件统一 `CTRL_H = 28`。禁止 22 / 24 / 26 |
| 圆角 | 控件 `RADIUS_CTRL = 6`，卡片 `RADIUS_CARD = 8`。禁止 3 / 4 / 7 |
| 间距 | 同一行控件间距只用 `SPACE_SM = 8` |
| 等分 | `n` 个并排控件时，单宽 = `(行宽 - 8 * (n - 1)) / n`，用 `add_sized` 固定画出。禁止 `min_size` 让按钮按文字变宽 |
| 右缘 | 同一卡片内，下拉、输入框、按钮的右边缘重合 |
| 输入框 | 按**外框宽度**布局。禁止 `TextEdit::desired_width(行宽)`：egui 会在文字宽度外再加 frame，框比按钮宽，并被卡片裁切 |
| 列溢出 | 固定列之和超过面板时，该表横向滚动。禁止列宽相加大于面板后互相叠压 |

建议新增（名称可调整，行为不要变）：

```text
theme::control_row(ui, row_width, gaps, heights) -> Vec<f32>
theme::sized_field(ui, tokens, width)   // 高 28 的 TextEdit / DragValue，外框=width
theme::sized_button(...)                // 已有 secondary_btn_sized / primary_btn_sized，调用方必须传入算好的宽度
```

`style.spacing.button_padding` 目前是 `(10, 6)`（`theme.rs` 约 199 行）。固定高度 28 时，垂直 padding 不要再把按钮撑过 28。

## 3. 串口工具

文件：`crates/wiparse-gui/src/serial_tool.rs`，函数 `SerialToolPanel::ui`（约 1763 行起）。

外框保留：`SIDEBAR_W = 272`，卡片水平内边距 8，左右各 1px 防裁切。改卡片内部。

### 3.1 缺陷

| ID | 位置 | 现象 | 原因 |
|---|---|---|---|
| S1 | 端口行，约 1827–1849 | 端口下拉右缘比波特率下拉短一截 | 下拉宽 `ctrl_w - 44`，刷新按钮 32，父级 `item_spacing.x = 0`（1814 行）。32+0 不能补上 44，右边空约 12px |
| S2 | 波特率自定义、文件名、保存路径、浏览目录，约 1897–2091 | 输入框比上下按钮宽，或右边被卡片切掉 | `desired_width(ctrl_w)` 是文字区宽度，不是外框宽度 |
| S3 | 新建 / 清空，约 1937–1961 | 与满宽的开始按钮左右不齐 | 半宽按间距 **6** 计算：`(ctrl_w - 6) * 0.5`，合同间距是 8 |
| S4 | 浏览目录 / 打开日志，约 2020–2029 | 两颗满宽按钮竖排，和上面的半宽行节奏不同 | 未走同一行网格 |
| S5 | 记录设置，约 1963–1967 | 普通 `selectable_label`，宽度随中英文变化 | 不是 28 高的通栏条 |
| S6 | 标签页，约 2232–2276 | 行高 28，页签高 24，箭头 22×24，圆角 3 | 与 `CTRL_H` / `RADIUS_CTRL` 不一致；箭头在未溢出时也占位 |
| S7 | 实时状态，约 1912–1922 | 单独一行 11px 强调字，和 28px 控件不在同一网格 | 字号也低于当前 `FONT_CAPTION`（12） |

刷新按钮本身已是 `secondary_btn_sized(..., 32×28)`，高度对，宽度和间距不对。

### 3.2 改法

设卡片内容宽为 `inner_w`。

1. 端口行：间距 8。刷新按钮 **28×28**。下拉外框宽 = `inner_w - 28 - 8`。
2. 波特率下拉、自定义波特率输入、文件名、保存路径、日志目录：外框宽 = `inner_w`，高 = 28。
3. 新建 / 清空：间距 8，各 `(inner_w - 8) / 2`，高 28。左右与开始/停止按钮对齐。
4. 浏览目录 / 打开日志：同一套半宽，并排，不再竖排两颗满宽。
5. 「记录设置」改成一行 28 高次级条，右缘对齐；展开后的字段仍用 `inner_w`。
6. 标签页：页签和左右箭头全部高 28、圆角 6。箭头只在内容宽度超过滚动槽时显示；未溢出时滚动槽吃满行宽。
7. 实时状态改到开始按钮上方的 28 高状态条：`● COMx · 波特率 · 实时`。不要再插一行 11px 字。

开始 / 停止继续用现有 `accent_button` / `stop_button`。它们是这一栏里唯一的主按钮。

## 4. 仪器控制

文件：`crates/wiparse-gui/src/instrument_control.rs`。

外框保留：左侧 `theme::SIDEBAR_W`（`ui` 约 1676–1686 行），右侧 `instrument_grid_row` / `instrument_row_column_widths`（约 5173–5198 行）。不要改 2×2 的分列算法。

### 4.1 左侧仪器卡

函数：`instrument_type_card`（约 6626 行）、`device_rack`（约 2044 行）。

| ID | 现象 | 原因 |
|---|---|---|
| I1 | 选中卡片时输入框、按钮右边被描边吃掉或比未选中时窄 | `content_width = panel_w - 11*2`（6615–6617、6675 行）在 **Frame 之外**用外层宽度硬算，没扣选中描边 2px。应在 Frame 内部用 `ui.available_width()` |
| I2 | 标题/状态与下面地址框右缘不齐 | 图标列 42px 后，文字列写成 `content_width - 42`（6688 行），水平布局还有默认间距 8，文字列多出 8px |
| I3 | 地址下拉、输入框、连接按钮三条右缘不重合 | 下拉用 `ComboBox::width`，输入框 `add_sized([content_width, 26])`，按钮用 `min_size`（6787–6822 行）。高度常量 `CARD_CONTROL_HEIGHT = 26`（6612 行）≠ `CTRL_H` |
| I4 | 「扫描 USB/LAN」缩在标题下左侧，和下面通栏卡片不对齐 | `device_rack` 约 2055–2074 行，按钮按文字自然宽度 |

改法：

- 删除 `CARD_CONTROL_HEIGHT`。卡片内控件高 28，圆角 6（卡片外框圆角改为 8，与 `RADIUS_CARD` 一致；现在是 7，约 6672 行）。
- 图标列改为 32，与文字列间距 8。文字列宽度 = 内部可用宽 − 32 − 8。
- 地址下拉、地址输入的外框都等于这条内容宽。
- 未连接：一颗通栏「连接」。已连接：「连接」「断开」各 `(内容宽 - 8) / 2`，`add_sized`，不要 `min_size`。
- 「扫描 USB/LAN」改为与卡片同宽、高 28 的主按钮。扫描中的 spinner 放在按钮右侧或按钮内，不要把按钮挤成短条。

### 4.2 示波器控制区

函数：`scope_unified_controls`（约 5753 行）。

| ID | 现象 | 原因 |
|---|---|---|
| I5 | 运行/停止/单次/自动设置这一行是齐的 | 四等分，`gap = 8`（5765–5810 行）。**保留，作为其他行的样板** |
| I6 | 时基/触发行右边是空的，「应用」不贴右缘 | 固定 80 + 68 + 72 + 68 +「应用」72，间距 10（5814–5872 行），和四按钮行的间距 8 也不一致 |
| I7 | 半宽格子里通道表横向溢出，刻度列里的 −/数值/+ 挤在一起 | 固定列 `40+28+96+96+168 + gap*5`，读数列再 `max(160)`（5878–5886 行）。半宽单元格装不下。步进按钮 `SCOPE_STEP_BTN = 24×24`（190 行） |
| I8 | 表头「Scale」「Pos」与中文「开 / 测量 / 读数」混排 | 5891–5901 行写死英文 |

改法：

- 时基行间距改回 8。`s/div` 数值框与触发电平框等宽；两个下拉等宽；「应用」固定 72 高 28；中间空隙吃剩余，行的右缘与上面四按钮对齐。
- 通道表默认四列：**CH（40）/ 开（28）/ 刻度（弹性）/ 读数（弹性）**。位置、测量类型放进该行的「更多」，或第二行，不要再占 96+168。
- 刻度列内：`−` 与 `+` 为 28×28 里的紧凑步进（若必须小于 28，只允许这一对，且在列内居中）。中间数值用列的剩余宽度，不要写死 36px（5949 行附近）。
- 表头全部走 `text(lang, …)`。

### 4.3 截图与波形按钮

| ID | 位置 | 现象 |
|---|---|---|
| I9 | `scope_screenshot_ui` 约 2520–2556 | 「屏幕截图」`min_size(88×28)`，「读取波形源文件」`min_size(128×28)`。中文长标签与英文短标签宽度不同，右缘漂移 |
| I10 | `scope_waveform_data_ui` 约 2656–2698 | 「读取屏幕」72，「导出…」88，和 I9 不是同一套 |

改法：同一行等分，高 28，`add_sized`。中文过长时按钮文字缩短（例如「波形源」「读屏幕」），完整说明放 `on_hover_text`（现有 tip 可保留）。通道下拉外框固定，不参与等分。

### 4.4 电源 / 负载 / 万用表

| ID | 位置 | 现象 |
|---|---|---|
| I11 | `source_channel_controls` 约 6217–6327 | 列宽 40/96/96/72/剩余，但 DragValue 按内容收缩，不撑满列；「应用」是 72×28 塞进 72 列，和输入框视觉宽度不一致 |
| I12 | `measure_toolbar` 约 3812–3884 | 「单次测量」「连续采样」88，「暂停」72，「停止」72，「周期」DragValue 插在中间 |
| I13 | `source_readings_ui` 约 3896–3921 | 「读取实测」「连续采样」都是 88，这一行相对整齐，保持等宽即可 |
| I14 | Dongle 控制，约 5688–5744 | `horizontal_wrapped` + `ui.button`，按钮按文字宽度排列 |

改法：

- 通道表每一列里的 DragValue 和按钮都撑满该列、高 28。表头与控件共用同一组列宽。
- 测量工具条：测量 / 连续 / 暂停 / 停止 四等分（未采集时隐藏暂停和停止，剩余按钮重新等分）。「周期」放到这一行右侧，或下一行，不要插在两颗主按钮之间。
- Dongle 的「扫描 / Ping / 恢复」等改为同一行等分，高 28。放不下的行再换行，换行后的按钮仍等分该行，不要自然宽度混排。

`card()`（约 6598 行）圆角 6 改为 `RADIUS_CARD`（8），与示波器格子一致。示波器格子 `scope_card_fill` 的半径目前是 6（约 5241 行），一并改为 8。描边继续用 Inside，避免裁切，这段逻辑不要改。

1. **`theme.rs`**：行网格与「外框宽度」输入框。补一个小测试：给定行宽 272、间距 8、2 列与 4 列，宽度之和加间距等于行宽。
2. **串口 S1–S5、S7**：只动左侧卡片。标签页 S6 单独一次提交，避免和卡片布局混在一个 diff。
3. **仪器 I1–I4**：左侧卡和扫描按钮。
4. **仪器 I5–I10**：时基行、通道表、截图/波形按钮。I5 的四等分算法当作参考实现，不要改行为。
5. **仪器 I11–I14**：电源通道表、测量条、Dongle。

每步只改布局。不改连接、扫描、SCPI、存盘逻辑。

## 7. 验收

在浅色和深色、中文和英文下各看一次。窗口宽度至少覆盖 1280 和 1600。

- 串口左侧每一行控件上沿、下沿一致，最右缘与「开始」按钮右缘重合。
- 中英文切换后，新建/清空、浏览/打开不换行、不裁字。
- 仪器卡未选中与选中（描边 1px / 2px）时，地址框和连接按钮右缘都不出界。
- 示波器「运行」行与时基行右缘对齐。
- 示波器半宽格子里通道表不出现列重叠；窄于四列时出现横向滚动，而不是画到邻接卡片里。
- 截图行、波形行、电源通道行、测量行里，同一行按钮宽度相等、高度都是 28。
- 开始/运行仍是唯一主色；停止仍是 `stop_bg`。

## 9. 工程修订（实现时）

诊断成立：不齐来自行内宽度和右缘，不是配色。实现时对原文做了这些修正，避免改业务路径：

- 扫描 USB/LAN、I2C 扫描保持次按钮，铺满该行并等高 28。转圈画在按钮上，不把按钮挤成短条，也不再做成第二个主色。
- 示波器通道的位置和测量放在第二行，不收进「更多」菜单。四列装不下时横向滚动。步进按钮在刻度列内为 22×22，行高仍是 28。
- 时基行：两个数值等宽、两个下拉等宽，应用固定 72×28 贴右缘，与运行行对齐。
- 截图、读屏、导出使用短标签，完整文案留在悬停。通道下拉保持固定 72，不参与等分。
- 测量条：空闲时单次/连续等分；采集中单次/暂停/停止重新等分。周期放到下一行。停止仍用 `stop_bg`。
- 电源输出按钮铺满输出列。Dongle 打开 UART 仍是该卡唯一主色；其余动作按整行等分。
- 串口标签页与左侧卡片同一批改完，不单独提交。
