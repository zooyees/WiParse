# 设备总览设计方案

日期：2026-09-25

读者：软件工程

对象：调试模式下的设备总览（`overview_workspace`、`paint_digital_twin_lab`、`paint_iso_twin_unit`）

效果图（示意现有立体面板的摆放，不是新的铭牌样式）：

- 待机：`docs/ui-overview-2026-09-25/steady.png`
- 协作：`docs/ui-overview-2026-09-25/ai-collab.png`

面板内容以代码里的 `paint_iso_twin_unit` 为准，效果图只说明位置、地面和协作点亮。

连接、填入、手工地址、单台控制台仍守 `docs/ui-instrument-experience-2026-09-24.md` 第 2 节。总览不新增连接。

---

## 1. 目的

总览是已连接设备的数字孪生。每台保持现在的立体面板和实测 LCD：电源通道、负载读数、示波器格子、万用表数字都留在 `paint_iso_twin_unit` 里。

要改的是位置和协作，不是把面板换成一张铭牌。

1. 面板按能量、观测、控制站在透视地面上，重连之后位置不变。
2. 有测试或 Agent 在跑时，只点亮这一步用到的设备之间的连线。
3. 单击面板进入该设备控制台。

---

## 2. 留下的，和拿掉的

留下：

- `paint_iso_twin_unit` 和 `TwinFace`。读数来源不改。
- `paint_twin_floor` 的透视地面。地面静止，去掉为扫描线服务的那条移动横线。
- 点击面板进入控制台。
- 已加载的设备照片。
- 测量或连接状态到达就重画。采集中按采样节奏刷新正在采集的那一台。

拿掉：

- 绕「工位核心」的均分角度。`paint_twin_hub` 整段删除。WiParse 不是一台设备。
- 每台都连向核心的折线和常驻粒子。`paint_twin_link` 改为设备与设备之间的连线，见第 4 节。
- 标题上的 `DIGITAL TWIN / LAB BENCH`、时钟、会话芯片、`LIVE`、`BUSY`。
- `paint_control_pipeline` 和标题下那段孪生说明。
- 台数一多就缩到 0.78 倍。放不下换第二排，面板保持现在的字号。
- 仅为装饰动画存在的无条件 80ms 重绘。

中文界面不出现 DIGITAL TWIN、LAB BENCH、SCAN、IDENT、LINK、CTRL、SESSIONS、LIVE、BUSY、STATION CORE。

---

## 3. 摆放

绘制顺序与 `devices` 的连接顺序分开。会话列表不动。

从左到右：

1. 能量：直流电源，然后电子负载。
2. 观测：示波器，然后万用表。
3. 控制：探针、Dongle、USB 桥，然后其它。

同一类按型号排序。两台示波器相邻。段与段的间距大于同类间距。不要复用扫描列表的 `kind_sort_key`，那套把示波器排在电源前面。

面板落在透视地面的近景一排，落点对齐到网格。七台以内一行。再多则第二排从左继续，仍按同一顺序，不让单独一台悬在第一台下面。

没有设备时，地面还在，正中一句「扫描并连接设备」。

顶栏左侧「总览」。右侧一盏灯和一个词：空闲、稳定、采集中、扫描、忙碌。扫描优先于采集。

---

## 4. 协作

连线画在设备与设备之间，沿能量 → 观测 → 控制。不经过画面中心的盒子。

没有测试、没有 Agent 任务时，连线是同一条淡线，没有跑点。

有运行中的步骤时，只加亮这一步用到的那几台和它们之间的线段。供能加亮电源和负载。采集加亮示波器，若这一步依赖已经稳住的电源，电源到示波器的线段用运行色。其余面板留在原位，读数照常更新。

步骤名和一句说明放在顶栏下方一行。来源按这个顺序取，取到即停：

1. 测试工具里正在跑的用例，以及运行器给出的当前步骤。
2. 否则用 Agent 正在执行的仪器任务短句。
3. 都没有则不画步骤，顶栏保持「稳定」或「空闲」。

这一行不能启动、暂停或下发设定。

---

## 5. 验收

- 电源、负载、示波器、万用表仍是现在的立体面板，能看到通道、格子和 LCD，而不是四行铭牌。
- 重新连接后，电源仍在能量段，示波器仍在观测段。
- 看不到工位核心、英文口号、流水线和常驻跑点。
- 没有测试或 Agent 时，连线不动。有步骤时，只有相关设备的连线变色。
- 点一台进入它的控制台。侧栏填入和手工地址仍能连接。
- 换排后面板字号与现在单台孪生一致，不随台数缩小。
