# WiParse Agent Router + Skill 开发与验证计划

日期：2026-11-12。原规划已进入实施；现行进展和未完成事项以 [开发进度](../verification/router-skill-20261112-progress.md) 和 [工作包核对](../verification/router-skill-20261113/development-audit.md) 为准。本文件保留目标与验收要求，不代表所有工作已完成或验证通过。

## 1. 目标与执行顺序

在现有 WiParse 工程 Agent 和串口助手之上增加轻量 Router、受约束的领域 Skill、组合任务与可追溯证据，复用 Rust 核心、现有 Tool 契约、权限、设备会话和 Testing Hub。用户要求：**先完成本计划目标开发，形成完整开发候选后，再按验证清单逐项测试、修复并复验**。当前开发阶段只做代码与契约静态审查，不提前编译、运行测试或反复打包；进入统一测试前冻结源码和环境。若测试发现问题，修复并重新验证受影响范围，保留失败记录。

原有目标不因引入 Skill 缩减：保留通用 Agent 与串口助手、模型配置、本地/公网模型、现有工具、人工确认、任务和证据；不得改变现有测试判定或假称实机通过。不依赖 GUI 框架重构或全新独立设备服务。工作区存在用户和其他工位未提交改动，先检查状态，禁止 reset、clean 或覆盖他人工作。

## 2. 范围及不变量

交付：注册表及内置技能包、路由、单技能/多技能组合、宿主执行对接、权限和确认、任务/证据/版本追溯、界面、诊断文档及全套验证。首期内置串口日志、波形、Qi 协议、测试结果诊断和无线充电保护/复充分析五个只读 Skill；设备辅助采集及测试执行 Skill 复用现有经过验证的设备/测试工具，权限不足、能力缺失或无法确认状态时明确阻止，不伪造实机能力。既有预留功能（如 FPGA 固件下载）不得宣称已实现；现有无线 live 后端或实机能力不足时不得绕过门禁。

Skill 是约束流程与知识，不拥有直接文件、网络、shell、硬件或任意脚本执行权；注册来源仅内置或明确经审核的可信包，首版不实现外部技能市场或任意代码。工具执行仍由宿主统一进行。Router 输出仅为候选，不授予权限；宿主在每次调用时重新执行既有来源、工程、设备、租约、测试锁、参数及具体动作确认。模型、日志、Skill 正文和工具返回均不能修改授权或系统策略。数据外发依用户已确认设置，明确范围、来源与预览；产品 PASS/FAIL 由确定性插件规则和实际限值产生，AI 仅辅助。

MT5820/MT5788：FT4222 I2C 前必须由本轮 TX 日志确认 RX 工作，旧日志、丢行、不完整证据、超时、取消不得触发 I2C；该规则由实际执行层强制。对结果未知动作不重试、不宣称未执行，需设备状态核对。实验参数和限值由用户配置，不编造产品规格。避免向既有设备运行路径追加未验证的自动控制。

## 3. 开发工作包及依赖

| ID | 工作包 | 内容与开发完成条件 | 依赖 |
|---|---|---|---|
| D01 | 基线和契约盘点 | 记录当前源码、实际入口、模型协议、Agent 工具清单、串口/工程助手共用与差异、权限、证据、运行状态、项目数据及改动归属；标出已知缺口与证据，不能把文档当实测。 | 无 |
| D02 | Skill 模型与注册表 | 定义 ID、版本、名称、描述、触发/排除、前置条件、输入、允许工具、效果等级、步骤、证据与输出、停止条件及兼容要求；解析严格校验、重复 ID/版本、缺项、超限、未知工具明确拒绝；内置可信资源随应用交付。 | D01 |
| D03 | Router | 显式用户选择优先；结合当前工程、页面、来源和能力做候选选择；允许多选及普通 Agent 兜底；不确定时展示候选供选择，输出选择来源、理由和状态。模型输出只作建议；缺失数据或用户授权不被路由补造。避免错误锁定所有后续轮次。 | D02 |
| D04 | 运行编排 | 将 Skill 步骤接入原 Session/Workflow：计划、预算、取消、任务身份、步骤状态、依赖、失败、恢复；跨 Skill 共享证据 ID，不重复操作设备，不自动重放；并行仅限独立只读任务且符合原执行器能力。 | D02、D03 |
| D05 | Tool/权限集成 | 映射技能允许工具与现有宿主工具交集；每次执行仍复核 scope、配置快照、身份、设备会话、测试锁及人工确认；来源切换后旧请求失效；串口与工程入口共享契约或写明差异，禁止新增旁路。 | D01、D04 |
| D06 | 内置只读技能 | 五个技能按各自前置、步骤、证据与不适用条件实现；禁止将本地缺失值填零、采样/截断当全量、分析候选当结论。无线需区分本轮/历史和未同步时钟；测试结果包含当次限值与运行 ID。 | D02–D05 |
| D07 | 受控辅助技能 | 实现示波器辅助采集和测试执行辅助的可用路径及能力检查，沿用当前已支持动作；展示具体目标、参数与影响，必要时确认；不可用时解释缺口，禁止跳过预检/锁或扩展底层驱动。 | D05、D06 |
| D08 | 证据与恢复 | 绑定任务、项目、Skill ID/版本、路由选择、来源身份/范围、算法、质量、时间、限制、工具结果和配置/限值快照；历史证据标历史，恢复重新核验；敏感信息、密钥不记录。 | D04–D07 |
| D09 | 界面与交互 | 在现有 AI 界面呈现自动选择/手动切换、组合步骤、所需数据、缺项/阻塞、证据与风险动作确认；紧凑简洁，不另设主页 AI 设置按钮；中英文及现有无障碍行为保持。 | D03–D08 |
| D10 | 集成和文档 | 配置/旧任务兼容、安装资源、禁用/回退策略、版本兼容、用户及开发说明；列出需真实模型/硬件才能完成的事项。确认所有工作包开发完成并冻结候选。 | D01–D09 |

每个技能独立定义：输入/有效范围、可用工具、输出结构、引用与覆盖率、无法取证处理、取消/超时与安全退出。不得把格式或说明文件等同于功能落地；必须接入真实现有工具调用路径及用户可操作入口。

## 4. 开发全部完成后的统一验证

建立独立证据目录，记录冻结源码 SHA256、构建产物、系统和工具版本、命令、数据来源、退出状态、日志、执行日期。测试不得操作未明确选择的真实仪器或污染用户项目。所有验证逐项标记通过/失败/未执行，不把模拟当实机。

| ID | 验证范围 | 必须覆盖 |
|---|---|---|
| V01 | 编译与回归 | Core、GUI、Agent、工具、串口及 Hub 相关自动测试；原有入口、模型兼容及旧配置/旧任务读取；开发完成后集中执行。 |
| V02 | 注册与路由 | 显式选择优先、五领域、跨域组合、模糊目标、缺失上下文、工具不可用、非法/重复技能、版本不兼容、正常兜底；不得产生静默误操作。 |
| V03 | 权限与对抗 | 未授权读/跨页、未确认写、参数越界、目标切换、重复/过期确认、伪造 Skill/日志指令、工具不在交集、路径和网络外发；不得绕过宿主。 |
| V04 | 工程任务与证据 | 五个只读技能逐项用真实格式文件及可控样本比对预期，覆盖缺测、截断、丢失、单位、时间未校准、过期结果及证据溯源；给出未确认，不产生假 PASS。 |
| V05 | 无线时序 | 本轮日志就绪后才能 I2C；旧日志、丢行、就绪超时、取消、无设备、未知结果均不访问或不重试；同一真实样本与模拟数据分开。 |
| V06 | 受控操作与恢复 | 使用隔离模拟器验证明确确认、配置/会话变化、设备繁忙、断线、超时、停止、结果未知、失败读回及不自动重放；记录设备实际行为与任务状态区分。 |
| V07 | UI/UE | 完整桌面交互：单技能、跨技能、修改选择、缺失数据、阻塞、确认卡、取消、来源切换、重开任务、空态、长文本、窄窗口、DPI/键盘；截图与窗口/版本记录。 |
| V08 | 模型与数据外发 | 模拟服务覆盖原生工具和 JSON 兼容；本地模型和公网模型分别实际测试（有环境时），核对请求预览、授权、脱敏、超时、取消、证据及 usage；无可用凭据标未执行。 |
| V09 | 真实硬件 | 用户可用台架上，在具备条件和既有授权时执行 TX 日志、FT4222/MT5788、MDO3014、DP832 和电子负载相关测试；标明型号、连接、配置、限值、物理状态及恢复。不可用明确未执行。 |
| V10 | 性能和质量评估 | 同样的冻结任务、模型及数据对照现有 Agent：路由准确/误路由、任务正确、证据回溯、关键错误、P50/P95 延迟、调用次数、已知 Token/费用；样本组一致，缺数据不推断收益。 |
| V11 | 发布准备 | 检查 Skill 资源与兼容性、无密钥、安装/升级和旧配置；如需打包部署遵循既有用户授权及目标目录，未满足实机或其他门禁时如实标识，不宣称完整工业验收。 |

统一测试报告需逐项列预期、实际、证据位置、缺陷和复验；真实模型、硬件与模拟分别列示。关键安全、设备状态、数据正确性问题未关闭不得宣布完成。硬件/凭据不可用时先完成所有不依赖部分，列出具体阻塞条件，不编造通过。

## 5. 分工、交付与状态

“软件工程”工位负责 D01–D10 的实现和 V01–V11 的验证与修复；系统架构负责统筹、审查需求及风险、核验关键结论。两方共享工作区，任何交叉修改先检查现状；不改变用户正在运行的实例和生产数据。开发完成后由软件工程提供变更文件、各 D 工作包状态、冻结哈希；测试阶段提供每个 V 的证据与报告；最终列出已交付、未验证、阻塞及风险。此计划是指令和验收目标，不表示开发已经完成。
