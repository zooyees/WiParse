## 4. 不可改的业务规则

FPGA：单工位、单 DUT。工程最多 500 个有名称的配置。矩阵状态只有真实的 TBT、TESTING、PASS、FAIL，以及中止、错误、无法判定；空结果和过期结果不能显示成通过。工程级信息是 DUT 身份和仪器绑定，测试项只写差异。计时原点是复位释放之后。同一资源上时间重叠的波形任务，预检必须拒绝。日志由插件在测试期间接管，结束后不能丢尾部。HEX/BIN 下载只留接口。限值改完即可用，报告写本次实际限值和配置快照。

无线：TX 为 MT5820，RX 为 MT5788。先用本轮 TX 日志确认 RX 已工作，再经 FT4222 I2C 访问，然后才动电子负载。不能拿上一轮日志或超时当就绪。示波器 MDO3014、电源 DP832 由 WiParse 的 VISA 连接。限值和负载型号由用户配置。寄存器以 MaxicCTP 里对应型号为准，不猜测地址。

AI：本地和公网分开。公网发送前展示内容和目的地，并要用户同意。AI 结论不能变成 PASS。设置放在设置页；串口页可以发起已有的单次提问，顶栏不放独立 AI 入口。

任何非幂等设备命令在超时、崩溃或断线后标记为结果未知，核对设备后再继续，不自动重发。WebView 里的恢复标记不是跨进程锁。

## 6. 界面规则

浅色、明亮、少装饰。内容外边距和面板间距 4 px。控件高度 28 px，正文 13–14 px，辅助文字 12 px。左栏默认且最小 200 px。七个工具始终排在顶栏，窗口窄时横向滚动，不收进“更多”。

同一屏只有一种主色用于当前页和主按钮。状态必须有文字。危险操作和普通按钮分开。不把 JSON 字段和内部错误码直接当作用户句子；细节放在可展开区域。

每个页面至少看四种状态：无数据、有数据、失败、长名称。窗口至少看 1100×720 和 1440×900。只改 CSS 数值不算完成，要在真实窗口里看。
