# 示波器与 DC 电源全通道平铺调整（2026-10-17）

## 调整结果

此前控制台仍依赖 `scope_channel` / `source_focus` 选择器，只渲染一个通道的控制区域。此次新增独立的全通道工作区，以设备声明的通道数（现有协议上限 4 路）生成控制卡片。

- **示波器**：所有支持通道同时展开，包含显示开关、垂直刻度、垂直位置、应用、测量项目、读数和读取按钮。运行、停止、单次和自动设置保持公共操作；时基、触发和屏幕预览独立排列。
- **DC 电源**：移除控制台/采集/设备页签以及通道选择器。每个通道的电压、电流限制、输出开关、过压/过流保护和实测值同时展开；采样、趋势、CSV 导出、设备信息、通信设置、维护和 SCPI 控制台在同一页面向下排列。维护操作直接展开。
- **自适应布局**：通道卡片等宽、同行顶端对齐、控件尺寸一致。空间不足时换行，保留所有通道，通过页面纵向滚动访问；不引入横向滚动或通道切换。
- **减少重复**：电源实测值仅保留在通道卡片内，趋势区保留采集控制和曲线，不重复排列同一组读数。

## 功能边界

所有通道命令显式携带通道号。渲染与窗口缩放不会发出仪表命令，电源应用设定不会自动开启输出。通道输入状态按设备和通道隔离；未声明保护能力时继续显示原有能力提示。采样、导出、清空的设备作用域及其它仪表控制方式保持原有语义。

示波器切换测量项目时清空该通道旧显示值，避免将旧项目结果直接显示成新项目读数。波形数据采集页中的数据源选择仍用于指定采集来源，不负责切换控制卡片。

## 验证

- GUI 完整测试：146 项通过；发布回归共 392 项 Rust 测试、67 项插件测试通过，1 项依赖外部波形文件的测试保持忽略。
- 逐通道点击：示波器应用/测量，电源设定/开启输出/关闭输出/保护，验证每条命令均指向对应通道。
- 通道布局：覆盖 1、2、3、4 通道以及 420、840、1400 像素工作区宽度，验证卡片数量、对齐、窗口边界及渲染无指令。
- 原有输入隔离、电源设定不自动开输出、短窗口、其它仪表、报告和工具页面回归通过。
- 现有界面渲染审计：主页面 252 组合、已连接仪表 432 组合、未连接仪表 32 组合，覆盖中英文、深浅色及不同尺寸。
- 新增单页完整性检查：确认 DC 页包含所有通道、趋势导出、通信设置、维护与 SCPI 控制台，且没有工作区切换页签。

验证采用模拟仪表、命令队列断言和真实 egui 网格渲染，不代表实体仪表联机验收。本次变更收录于 1.1.35 发布包；既有 1.1.34 ZIP 不包含本次变更。发布版回归结果以包内 `docs/verification/release-1.1.35.json` 为准。
