# 示波器控制页比例与对齐修订（2026-10-17，1.1.35 后续源码修订）

## 问题与调整

用户截图中，四张通道卡片横向占满页面，每张约 361 像素高；下方预览区则用固定高度承接剩余宽度，形成超宽横条。重复的显示行、上下排列的参数和通栏测量按钮进一步增大了卡片体积。

本次采用示波器专用布局：

- 工作区宽度达到 1100 逻辑像素时，左侧四通道按 2×2 排列，右侧为屏幕预览，两区顶部和底部对齐。工作区内容最大宽度为 1680，避免超宽屏继续无界拉伸。
- 宽屏单张通道卡片约 223 像素高，相比原来减少约 38%。显示开关移到标题右侧；刻度和位置并排；读数与简短的“读取”按钮同排。窄卡片自动将刻度和位置上下排列。
- 窗口空间不足时，通道按宽度换行；公共触发区和预览区向下排列。预览高度随宽度计算，不再固定为 280 像素。真实截图继续按原始比例缩放，不拉伸图片。
- 时基、触发源、触发电平、触发边沿统一为一组横向公共控制；窄窗口自动换行。触发输入控件统一为 28 像素高。
- 统一预览标题、圆角和背景；减少重复的蓝色主按钮，修正浅色主题中截图按钮的文字颜色。

DC 电源的单页布局保持不变。通道命令仍显式携带通道号；应用通道参数和公共触发继续分别提交，页面绘制不发送控制指令。

## 验证

148 项 GUI 测试通过，包括原有中英文、深浅色、小窗口和不同显示缩放回归。

新增检查使用实际 egui 输出的矩形，而非仅验证布局参数：

- 通道卡片高度小于 300 像素，未超出窗口边界。
- 宽屏下四张卡片按两行对齐，预览与卡片区域上下对齐。
- 宽屏与普通窗口的预览画布宽高比保持在 1.3–2.4 范围，避免超宽条状画布。
- 点击 CH3 标题开关仅改变 CH3；应用公共触发时，时基、源、电平及边沿均正确传递。
- 各通道的参数应用和测量，以及 DC 电源的设定、输出及保护操作回归通过。
