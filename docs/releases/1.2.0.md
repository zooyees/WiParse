# WiParse 1.2.0

2026-10-18

- 新增 Testing Hub 配置工作区：结构化表单、校验、配置版本和审计、导入导出、归档恢复、运行快照和预检绑定。
- 测试矩阵按实际数量显示，最大支持 500 项；支持筛选、选择、失败定位和结果跳转。
- 完成 FPGA 插件 0.3.1 接入与显式模拟验证，附带五项配置及可跳转证据的模拟报告。真实硬件 adapter 和工业验收仍待完成。
- 新增全局 AI 接口设置，支持兼容 Chat Completions 的 DeepSeek、千问等服务，以及 Responses/SSE；密钥不写入报告，调用需用户明确触发。
- CLI/MCP 增加配置与矩阵接口；随包附带离线 schema 校验依赖。
- 保持便携路径：用户配置保留相对目录，仅在运行边界解析；移动目录后重新预检。

使用说明：`docs/TESTING_HUB_WORKSPACE.md`、`docs/FPGA_PLUGIN_INTEGRATION_REVIEW.md`、`docs/AI_INTERFACE.md`。验证记录位于包内 `docs/verification/release-1.2.0.json`。未连接真实仪器和云端 AI token，模拟数据不代表产品合格验收。
