# WiParse 1.2.2 · 2026-11-10 AI整改与原生协议分析增补

本记录对应 `cursor/four-job-shell-and-marketplace` 分支上的原 egui 框架。产品、CLI、Service及MCP版本继续为1.2.2，使用日期与Git标签区分此次增补；没有混入Tauri迁移试验目录。

## 功能与界面

- 串口AI以本地处理引擎支持当前文件、指定行范围、选区和授权日志库。关键词/排除词、正则、归一化分组、数值与阈值统计在本地流式运行，模型只接收有界摘要、证据与覆盖说明，支持游标续扫。保留原串口行数限制及滚动/接收流程。
- 波形协议结果回到软件内，提供紧凑原生报文、字段和协议叠加显示；SCP数据帧列表不显示PING，底层协议结果仍保留相应信息。USBPD默认阈值0.4 V、SCP默认阈值1 V。默认纵轴按信号自适应并设置合理的自动适应下限，保留手动小信号调整能力。
- 收紧波形主区域、工具卡片和侧栏间距；调整数据分析规则、报告项目导航及仪表表单的对齐和窄窗口布局。
- 浅色模式使用独立语义配色：正文、状态、按钮前景、曲线、坐标、光标、协议标记及输入边界按主题适配；修正AI窗口与输入区域超出窄视口的问题。

## AI架构与缺陷整改

新增跨工具工程任务入口，提供38个原生工具方法（与MCP的6个高层工具不是同一计数）。覆盖串口日志与监控、波形与协议、数据统计、报告、测试生命周期、工程计算及受限仪表操作。

- 统一测试占用检查，设备动作逐次确认；确认和派发期间复查工程、数据来源、配置与实际设备能力。截断的模型回复即使是合法JSON，也不执行动作。
- 证据编号在会话内不复用，追问保留来源、任务与结果。取消、超时以及内部轮询期间的在途操作均保留审计，未知结果不会伪称撤回或成功；服务配置改变时清除待发送对话历史。
- 任务只绑定实际使用或待确认的资源，普通浏览其他页面不会误取消任务。格式错误最多修复一次；轮数、工作线程及输出预算继续受限，极端分页参数在宿主计算前拒绝。
- 修复长日志行尾告警漏检和返回样例不包含匹配文本的问题。通用助手复用串口助手的日志库范围与监控接口。
- 波形通道、测量和协议帧携带索引、载入期trace标识、解析设置、通道映射、lane、generation及时间窗来源。新增PWM频率、周期分布/抖动、脉宽与同步双通道死区统计，循环支持取消。
- 实时数据统计固定查询开始时的截止点，新流入数据不干扰当前结果；空数据不标记完整，也不替换为零。
- 报告检索使用工程内不透明ID、全文分片与续扫，不受界面预览长度限制；检索前重新检查规范路径范围。
- 测试受理返回独立UUID，由主机持续跟踪实际进程状态，不再被AI单工具等待时限截断。配置先生成差异草案并调用既有schema/路径校验，确认后仅应用到未保存编辑区；仍需保存及重新预检。
- 仪表调用检查类型、真实通道与能力。截图申请可跟踪job ID并等待真实完成；命令完成与物理验证明确分开。计算器摘要补充单位、SI值和Q/RC结果，缓存结果提示重新计算。
