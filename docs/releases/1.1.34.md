# WiParse 1.1.34

发布日期：2026-10-17。

重新组织仪表控制页的操作顺序与空间分配。设置和结果分栏且独立滚动；端口设备使用参数与操作两列，取消等高卡片和无意义留白，添加页内任务定位。修复禁用按钮容器导致的横向撑宽，统一 SCPI 输入与按钮尺寸。采集读数按通道及电压/电流/功率排列，清空和 CSV 导出只处理当前设备。所有设置继续使用原有命令队列与设备能力约束。

详见 [系统性评审与实际界面](../ui-instrument-workspace-1.1.34.md)。仪表侧栏显示程序实际版本。请从本包 `bin/WiParse.exe` 启动；已有运行中的旧版不会被强制终止或覆盖。`start-ui-demo.ps1` 使用隔离配置创建模拟仪器，正常启动不创建模拟设备。

包内提供 GUI、CLI、服务、匹配的调试符号、MCP、插件、模拟报告与验证记录。MCP 和插件业务契约未因本次布局调整改变。未进行本次真实仪表或 DUT 验收，不改变工业批准状态。
