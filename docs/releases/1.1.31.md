# WiParse 1.1.31 版本说明

发布日期：2026-10-16（Asia/Shanghai）。Windows x64 开发验证版。

## 仪表控制重构

- 重构八类仪表、未连接页和设备总览。紧凑设备列表取代重复连接大卡片，统一参数行、分段选择、开关、动作和读数层级，沿用软件的深浅主题与蓝色强调色。
- 电源和示波器按当前CH操作；电源的设定与实测V/A/W分离，保护按需展开。示波器通道、时基与触发分组，常用采集按钮保留在工具栏。
- 探针按连接/烧录/内存/RTT组织；USB桥和Dongle按接口组织参数，网络配置、维护与SCPI诊断独立。
- 切换通道不发送控制命令；电源应用设定不自动开启输出；读数缺失显示“—”；错误与收发记录按设备隔离。万用表不再回退显示其他测量功能的旧值。
- [完整评审、设计说明与实图](../ui-instrument-redesign-2026-10-16.md)。图中读数均为模拟展示夹具。

## 测试报告

- 左栏只显示“测试项目 / 批次 / MD报告”。波形、图片、JSON/JSONL、日志与PDF从正文链接打开，可返回报告。
- 单击批次打开MD；缺少MD时明确提示并清除上批次正文，不再打开任意附件。报告名称与展开图标改进，兼容旧插件的普通文档分组。
- 示波器/串口监控新报告使用“总报告 / 会话 / 采集轮次”层级，图片改为正文链接。公共附件入口按用途分节，保留原始数据。

## 包内容与使用

解压 `WiParse-1.1.31-dev.zip`，运行 `start-wiparse.ps1`。新版EXE位于 `bin/`，插件位于 `test-tools/plugins/`，MCP及离线依赖位于 `mcp/wiparse/`。目标机运行MCP/插件仍需Node.js 18+。

无需实物查看界面时运行 `start-ui-demo.ps1`，该入口使用独立配置，显示标注为模拟的设备。它不替代实物测试。正常启动入口默认不会启用该展示模式。

“测试报告”选择default并刷新，可查看 `ScopeSerialDemo / 20261016_120000`：三个模拟场景，包含MD、三份双通道ISF、三份CSV、三张图片及串口记录。全部为合成数据，PDF未生成，不代表产品合格。

GUI、CLI、Service、MCP统一为1.1.31。插件版本：example-smoke 0.2.3，scope-serial-monitor 0.6.2，DAP/I2C/UART 1.0.3，netcfg 1.2.2；无线充电检验插件维持0.1.1。

## 验证与范围

验证包含Rust工作区、插件与MCP回归、432组仪表布局、CH选择/设定派发交互，以及Release GUI运行和MD/JSON/日志/图片/ISF打开。服务接口和四组37用例模拟回放、ZIP CRC与SHA256、EXE/PDB身份、离线MCP和报告附件完整性记录随包保存。

本版没有连接实物仪表或DUT验收。自动化基础服务与无线充电插件仍为 `industrial_approved=false`；Dongle固件接入、保护闭环及G2—G4现场验收范围见系统契约与实施评审。本次不发布在线升级stable清单。
