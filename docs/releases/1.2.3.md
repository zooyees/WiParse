# WiParse 1.2.3 工程 Agent 版本记录

2026-11-11。基于 v1.2.2-ai-20261110（d4362bc），沿用 egui 主线。GUI、CLI、设备服务与 MCP 使用 1.2.3。

- 串口与工程助手共享交付状态和证据索引，支持排队、修正、取消、来源变更检测和工程级任务记录。已验证报告可续用，来源或设备会话变化后重新核对。对未知结果的设备动作保留人工读回记录。
- 支持可配置文本分帧、字段与时间戳提取。数据分析文件的大数据量曲线采用本地分页历史，报告可导出完整 CSV。报告链接定位到原始行、字节偏移、波形采样范围和协议帧对应的时间窗。
- 波形 CLI 支持离线测量。互补驱动测量区分换向方向，记录采样分辨率、不完整边界和无法确定的探头延时。
- 串口触发采集保留首个异常上下文、采集缺口、设备命令回执。无线充电插件增加工位录制数据、适配器兼容矩阵、批次比较、充电传输区间与通信质量诊断。设备服务支持基于锚点的多来源时窗对齐。
- 工程评测支持数据与量规冻结、独立分组、匿名评审、交付附件摘要验证、按成功交付核算 Token 和时延。默认 AI 输出预算改为 8192。
- 升级建议在独立目录启动，保留目标机器现有工程、配置和密钥。回退可从旧目录运行 1.2.2，项目中的 Agent SQLite 和报告文件请随工程备份。插件依赖本机 Node 环境，真实设备仍依赖相应驱动。
- 集中回归通过 320 项核心、312 项 GUI、6 项服务和 286 项插件测试。百万行回源与独立评分脚本另有核对。真实双模型盲评、Dongle 专用传输和通电保护验收尚未完成。
