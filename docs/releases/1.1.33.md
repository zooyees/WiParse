# WiParse 1.1.33

发布日期：2026-10-17。

仪表控制台改为平铺网格，取消多层参数和接口页签。示波器通道、触发及读数、电源设定与保护、USB 桥各接口、Dongle 的 DAP/UART/I2C 常用操作直接显示。统一面板列宽、行高和按钮尺寸，随窗口宽度自动换列，并明确接口按钮名称。

详细说明见 [布局评审与修正](../ui-flat-instruments-1.1.33.md)。发布包包括 GUI、CLI、服务、匹配的调试符号、MCP、插件、模拟报告与验证记录。使用 `start-ui-demo.ps1` 可在隔离配置下查看模拟仪器，正常模式不创建模拟设备。

测试覆盖布局、编辑隔离、命令路由与原有功能回归；未进行本次真实仪表或 DUT 验收，不改变工业批准状态。
