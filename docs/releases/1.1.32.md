# WiParse 1.1.32 版本说明

发布日期：2026-10-17，Asia/Shanghai。Windows x64 开发验证版。

本版系统检查七个主要工具及相关接口，重点修正仪表内部面板和串口查看行为。详细问题、修正映射、跨功能影响及验证边界见 [全功能检查报告](../system-audit-1.1.32-2026-10-16.md)。

## 主要变化

- 仪表参数列宽、控件高度和操作按钮统一对齐；窄窗口先显示设置，当前通道写入参数标题；保护区与其他区域保持一致。
- Dongle 参数页直接核对连接摘要并展开编辑；I2C 操作先应用当前端点，避免使用旧地址。
- 串口日志区向上滚轮固定历史视图，继续接收、保存和解析；点击右侧底部向下三角跳到最新并恢复跟随。查找与选择在同一份历史数据上执行，API 与数据分析继续使用实时数据。
- 保留 5000 行显示上限、8192 条接收队列、400 条/4 ms 消费限制及 5 秒日志刷新参数；优化连续接收调度、无数据时的界面重绘、附加串口消费和最大行宽维护。
- 串口查找区与显示选项分行；计算卡片保留最小高度并支持整页滚动，改善小窗口操作。
- 延续 MD 报告主视图和正文附件跳转。GUI、CLI、Service 与 MCP 更新至 1.1.32；插件版本沿用 1.1.31。

## 使用与验证

解压 `WiParse-1.1.32-dev.zip` 后运行 `start-wiparse.ps1`。需要查看模拟仪表界面时运行 `start-ui-demo.ps1`。软件在 `bin/`，MCP 及离线依赖在 `mcp/wiparse/`；使用插件/MCP 仍需 Node.js 18+。

测试报告的 `ScopeSerialDemo / 20261016_120000` 为三个合成场景，包含波形、图片与日志。它用于检查显示和链接，不代表产品通过。

验证涵盖 Rust 工作区、插件与报告、MCP、服务 HTTP、无线充电模拟回放、多语言/主题/尺寸 UI、控件几何及实际点击、最终 Release 启动和包内容检查。实际结果随包保存在 `docs/verification/`。

未进行实物 DUT、仪表和工业工位验收，`industrial_approved=false`。完整异步写盘架构、无限过载和极长无换行输入不作为本版已完成能力；本次不发布在线升级 stable 清单。
