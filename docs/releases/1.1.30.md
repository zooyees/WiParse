# WiParse 1.1.30 版本说明

发布日期：2026-10-13（Asia/Shanghai）。本版为 Windows x64 开发验证版本，GUI、CLI、独立服务与 MCP 版本统一为 1.1.30。

## 改进与修复

- 数据分析、波形、串口、仪表、测试报告、集成测试六个工具左侧栏支持鼠标拖动调整宽度、双击恢复默认；各页独立记忆当前运行宽度，窄窗口保留右侧内容空间。
- 仪表卡片随侧栏伸缩；插件表单标题、用例和参数不再重叠，预分配界面区域统一裁切和定位。含 1.1.28/1.1.29 尚未推送的 UI 修正。
- 测试报告正文、列表、表格中的多个数据链接分别响应普通单击；支持长内容自动换行、转义竖线、中文/空格/括号路径和图片。JSON/JSONL 内嵌显示，附件查看后可返回 MD。主报告选择排除 JSON 附件。
- 内置插件 MD 提供原始日志及附件入口；示波器串口报告使用相对链接，可移动整个运行目录。
- 无线充电自动检验插件提供逐用例检查数据、覆盖率、配置限值、首个异常及处置、原始回放和文件哈希。执行成功与产品/回放判定分别保存，未知状态不盲目重试。
- MCP 初始化版本直接读取 package.json，六个既有工具保持兼容，report.open 不返回文件正文。
- 包含自动化基础服务、协议输出数量保护与此前的软件规格落地成果；职责和未完成项见 docs/specs/wireless-test/04-software-implementation-review.md 与 05-plugin-implementation-review.md。

## 包内容与使用

文件名：`WiParse-1.1.30-dev.zip`。解压后运行 `start-wiparse.ps1`，程序位于 bin，插件位于 test-tools/plugins，MCP 位于 mcp/wiparse。Node.js 18+ 仍需在目标机安装；MCP 依赖随包提供。独立开发服务通过 start-automation-service.ps1 启动，默认仅本机访问。

“测试报告”选择 default 并刷新，可查看 ScopeSerialDemo / 20261013_231510。三轮场景分别为 PING、正常功率传输、VIN 欠压后关闭 PWM，包含 MD、3 份双通道 ISF、3 份 CSV、3 张截图、串口日志和采集记录。全部是合成数据，PDF 未生成，不能代表产品合格。

软件升级保留使用者的 config.json、数据库和既有项目。不要直接用示例配置覆盖现场配置；用独立目录解压验证。归档内 symbols 保留三个 EXE 对应的 PDB，用于后续 Windows 崩溃分析。

## 验证与限制

验证记录随包放在 docs/verification。Rust 工作区 371 项通过、1 项忽略；GUI 包含其中 128 项。Node 插件 65 项通过；MCP 六工具初始化及四项报告路由通过；服务 13 项接口检查与四组 37 用例回放通过；新版 GUI 七页及 MD/JSON/日志/图片/ISF 打开通过。包括 Release 编译、Rust/GUI 和 Node 回归、MCP 协议初始化与路由、四组真实本地服务回放、GUI 启动/七页切换，以及归档 CRC、SHA256、EXE/PDB 匹配和模拟报告链接完整性。

本次不连接实物仪表。自动化服务和无线充电插件仍为工业联调基础，industrial_approved=false；未实现的 Dongle 实时捕获、设备刺激/保护闭环和 G2—G4 现场验收不能由模拟回放替代。未向在线升级服务器发布 stable 清单。
