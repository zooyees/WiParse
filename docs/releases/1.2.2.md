# WiParse 1.2.2 EXE 预览说明

2026年10月18日。配套 FPGA 插件 0.5.0。本轮先交付可运行 EXE 目录，用户确认后才完整打包 ZIP。

## 改进

- 测试矩阵以工程配置清单为主，尚未预检也显示实际全部测试项；0/5/20/500 项不补空行，继续虚拟化滚动。点击测试名称查看详情，执行勾选独立。
- 右栏展示当前状态、历史来源、判定实际值/限值与项目内证据入口；窄屏详情置于列表下方。未保存、禁用、未选中、异常和过期历史区分显示。
- 新建草稿立即插入列表并定位，不可执行；保存后转为正式配置，失败保留输入，放弃则移除。刷新保留草稿，容量包含草稿占位。
- 新增工程设置，集中维护 DUT 约束及仪器绑定。逐项仅保留精简属性与固件、复位、日志、采集、判定等业务参数。COM/Dongle 日志和电源由测试项显式引用共享角色，不覆盖绑定。
- 旧配置先预览字段差异与角色映射，点击提交后原子备份及迁移；存在冲突则拒绝合并。原始20项迁移源保持不变。
- 共享配置按 project/test/plugin 隔离，同一范围更换仓库仍共用锁和恢复日志。共享 revision/hash 纳入预检、运行快照、报告和恢复校验，活动运行期间禁止修改。
- FPGA 结果升级为 /2，核对工程范围、用例、运行、数字尝试序号、UUID、用例及共享哈希。旧结果缺少来源时保留历史查看入口，不作为已核验的当前结论。
- MCP 增加工程配置、迁移及结果详情接口。保留既有 Stop、取消与租约保护。

## 验证与范围

全工作区 Rust 426 项、完整 Node 251 项通过；其中插件专项160项（含112项故障矩阵）。MCP 6个工具、20项Hub路由及4项报告路由通过。实际schema/UI的52个渲染场景覆盖640/1100/1440/1920宽度及选定中英文、明暗主题；规则编辑与矩阵行选择有指针事件回归。

20项业务配置模拟验证正向20 PASS、负向20 FAIL，分别检查62个报告证据链接；只选2项运行仍保留20项工程清单。保留原10项COM、10项Dongle日志、5项电源复位及15项Dongle复位组合。模拟验收缩短计时仅限隔离回归工程，不更改源配置及判定限值。

以上为软件回归与模拟运输验证，不代表真实仪器、工业认证、最长老化、精确T0或实际500项全程执行已验收。最终EXE验收与构建哈希见本轮验收记录。

## 预览操作

在预览目录内运行 `bin/WiParse.exe` 并保留旁边依赖；插件运行需要 Node.js 18 或更新版本。进入 FPGA 插件的“工程设置”，先预览附带20项旧示例的迁移映射，再明确提交。已有真实工程不会被静默迁移。模拟测试请在本轮参数选择模拟模式；默认真实硬件模式仍要求已验收适配器。
