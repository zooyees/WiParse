# WiParse 1.2.1

本版整合 Testing Hub 通用编辑器、FPGA 固件测试插件 0.4.0、AI 助手和仪器连接布局修正。最终构建、运行检查与产物哈希以包内 `docs/verification/release-1.2.1.json` 和 `release-manifest.json` 为准。

## 使用变化

- 配置按业务分组浏览；短参数在宽屏并排，窄屏堆叠；可选参数集中添加，高级设置集中收纳。打开页面不会擅自补写默认值或修正非法常量。
- 判定规则呈现摘要及当前详情，可创建和切换日志、数值、组合规则；中文标签和单位由声明统一管理。引用可选择，仍被引用的数组项目不能直接删除。
- 文件浏览与校验在后台计算实际 SHA256，返回相对配置目录的路径，防止结果覆盖已切换或已修改的字段。预检和运行仍独立校验文件。
- 工作区只保留一个执行控制区。保存、预检、当前执行和上次结果分开；暂停在当前项归档清理后生效，停止阻止启动后项。最多500项按实际数量显示。
- FPGA 0.4.0 修正无效规则误判、Dongle UART通道匹配、超时/停止/直接报错的取消确认、同项并发取消、未知状态保留租约、归档失败和未完成运行恢复。证据和实际限值进入中文报告。
- AI 助手支持连续对话和安全 Markdown 显示，独立连接测试与分析请求，保留失败后的输入并可重试。用量简洁显示，原始元数据折叠；未保存的服务修改明确提示。兼容 DeepSeek、千问等配置接口。
- 仪器连接和查找设备按钮使用统一宽度及间距，避免中文按钮被挤成竖排。

## 模拟数据与兼容

保留原始20项 FPGA 业务配置及其时序。随包历史报告来自独立、缩短采集时序的模拟快照；历史通过不代表当前配置已经测试。选择模拟模式后重新预检并运行；原始配置持续时间较长属正常。固件示例是占位数据，不能下载到产品。

FPGA 0.4.0 最低要求 WiParse 1.2.1；旧版通用插件继续兼容。通用声明见 [HUB_UI_FIELDS_CONTRACT.md](../HUB_UI_FIELDS_CONTRACT.md)。部署目录可移动，路径在文件/进程边界解析，不在发布配置中保存开发机绝对路径。

## 验收边界

软件验证使用模拟运输及确定性故障注入，未连接真实仪器或 DUT。20万行日志压力检查不等于真实串口吞吐、采集定时或最长老化验收。DC/Dongle复位时序、设备取消和物理安全恢复仍须合格适配器与实机验收。完整发现入口一致性保留后续工作。

硬件适配器不满足能力时入口阻断；不静默回退模拟。HEX/BIN下载仍未实现，启用时预检阻断。`industrial_approved=false`。
