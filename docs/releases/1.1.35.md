# WiParse 1.1.35

发布日期：2026-10-17。

示波器和 DC 电源改为全通道平铺控制：每个通道独立显示参数、操作按钮与读数，不再切换通道查看控制项。DC 电源进一步取消工作区页签，将设定、输出、保护、采集、趋势、导出、设备设置和维护放在同一页面。卡片等宽排列，窄窗口自动换行。

所有控制命令显式指定对应通道。电源应用设定与开启输出保持独立；原有设备能力约束、采样与导出行为保持不变。

[调整说明及实际界面预览](../ui-all-channels-2026-10-17.md)。本包包含 GUI、CLI、服务、匹配调试符号、MCP 离线依赖、插件、模拟报告和验证记录。请先退出旧版，再从本包 `bin/WiParse.exe` 启动，确认侧栏版本为 **1.1.35**。

模拟仪表入口为 `start-ui-demo.ps1`；正常启动不会自动创建模拟设备。本次不包含实体仪表或 DUT 验收，不改变工业批准状态。

验证：392 项 Rust 测试、67 项插件测试通过，1 项外部波形测试保持忽略；包含全通道按钮路由、单页功能完整性及中英文/深浅色/不同窗口尺寸的 UI 回归。发布版启动与包完整性结果见包内 `docs/verification/release-1.1.35.json`。
