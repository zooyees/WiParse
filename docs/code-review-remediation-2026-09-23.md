## 波形协议同步变更

- 修正手动数字阈值的伏特单位、波形边界外采样和 UART 截断/奇偶/停止位错误传播。
- 新增 USB PD：CC BMC、4b5b、SOP/Reset、消息头、CRC32、固定 PDO/PPS 摘要。
- 新增 UFCS：UART 8N1、SOP、控制/数据/厂商帧长度、CRC8 0x29、请求摘要。
- 新增 SCP：单线 NRZ、MSB first、奇校验、1/4 UI 分隔、PING、CRC8 0x39。
- GUI 和 `ui.wave.bus` API 已加入三种协议、信号通道、阈值、UFCS 波特率和 SCP UI 设置。

## 验收边界

自动化测试使用合成波形，可以确认帧结构、CRC 路径和错误标记，但不能替代探头接法、模拟前端幅度、采样率、抖动及厂商扩展报文验证。发布前建议至少使用一组真实 USB PD、SCP、UFCS 波形回放，并完成报告建议的串口持续采集、磁盘故障、多仪器并行和更新中断测试。
