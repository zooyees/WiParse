- 旧配置先预览字段差异与角色映射，点击提交后原子备份及迁移；存在冲突则拒绝合并。原始20项迁移源保持不变。
- 共享配置按 project/test/plugin 隔离，同一范围更换仓库仍共用锁和恢复日志。共享 revision/hash 纳入预检、运行快照、报告和恢复校验，活动运行期间禁止修改。
- FPGA 结果升级为 /2，核对工程范围、用例、运行、数字尝试序号、UUID、用例及共享哈希。旧结果缺少来源时保留历史查看入口，不作为已核验的当前结论。
- MCP 增加工程配置、迁移及结果详情接口。保留既有 Stop、取消与租约保护。

## 验证与范围

全工作区 Rust 426 项、完整 Node 251 项通过；其中插件专项160项（含112项故障矩阵）。MCP 6个工具、20项Hub路由及4项报告路由通过。实际schema/UI的52个渲染场景覆盖640/1100/1440/1920宽度及选定中英文、明暗主题；规则编辑与矩阵行选择有指针事件回归。

20项业务配置模拟验证正向20 PASS、负向20 FAIL，分别检查62个报告证据链接；只选2项运行仍保留20项工程清单。保留原10项COM、10项Dongle日志、5项电源复位及15项Dongle复位组合。模拟验收缩短计时仅限隔离回归工程，不更改源配置及判定限值。

以上为软件回归与模拟运输验证，不代表真实仪器、工业认证、最长老化、精确T0或实际500项全程执行已验收。最终EXE验收与构建哈希见本轮验收记录。

## 预览操作

在预览目录内运行 `bin/WiParse.exe` 并保留旁边依赖；插件运行需要 Node.js 18 或更新版本。进入 FPGA 插件的“工程设置”，先预览附带20项旧示例的迁移映射，再明确提交。已有真实工程不会被静默迁移。模拟测试请在本轮参数选择模拟模式；默认真实硬件模式仍要求已验收适配器。


## 2026-10-25 串口 AI 与 FPGA 布局预览增补

本次随包 FPGA 插件为0.5.4；下方为当前增补，前文保留10月18日初始预览记录。

串口工具移除数据分窗，日志工具栏增加 AI 窗口，右侧直接显示可调整宽度的对话。复用全局AI设置，提供多轮Markdown分析、当前数据及选区采样、15–300秒有界新增数据监控。用户勾选允许自动化后，AI可请求当前串口接收启停及AI监控启停；宿主验证动作、原请求授权、当前工程/数据源/会话及测试运行锁，显示真实执行结果。不会发送任意串口字节或改写测试判定。串口接收限额、日志保存、滚动查看和跟随最新行为保持不变。

FPGA工作区将标题导航、项目与执行、配置管理分层；长名称两行卡片统一宽度，勾选和编辑独立，暂停与继续共用槽位，批量和传输动作收纳。5/20/500项按真实数量呈现，保留已有参数、运行门禁与结果来源核验。

原测试报告截图直接显示和源数据后台采集修正一并保留。验证记录与实际限制见本轮评审和验证目录；本次不创建ZIP、不覆盖已有预览。


## 同日后续调整：串口智能对话工作台

目标从摘要助手调整为通过对话进行监控、处理、分析、预警与平台设备协同。右侧栏统一间距、边界和控件高度，固定底部输入，监控页使用目标卡、固定标签列和三列等宽指标卡。最近日志、选区和仅提问可明确选择。

对话可设置监控目标、周期、关键词与数值阈值；本地规则及时显示原始证据，并优先安排AI异步分析。AI可使用白名单平台目录发现设备、读取缓存状态、执行类型化示波器/电源/负载操作、测量、截图、采集源波形及调用日志解析等能力。实际工具结果自动交回AI继续判断，最多六次调用；设备结果保留到后续追问。新增instrument.job.get核对实际完成，取消/超时不冒充已撤回或成功。

控制默认关闭，读目录及监控本身无需设备控制授权；输出和采集等设备操作必须开启控制并通过工程/源/会话/测试锁核验。工具失败或未知状态关闭后续设备控制。原始串口采集限额、日志滚动/保存以及已有测试、报告功能不变。完整影响范围与限制见 `reviews/serial-ai-intelligent-workbench-2026-10-25.md`。
